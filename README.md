# GraphPlotter - Построитель графика функции

## Описание
Учебная программа для курсовой работы.  
Строит график функции **y = (x-2)²** в диапазоне x ∈ [0.9; 4.1] с шагом 0.2.

## Функциональность
- Построение графика с помощью компонента Chart
- Вывод координат точек в ListBox
- Сохранение координат в текстовый файл (.txt)
- Обработка ошибок при сохранении
- Автоматическое завершение всех процессов при закрытии

## Технологии
- C# / .NET Framework
- Windows Forms
- Chart Control

## Как запустить
1. Открыть решение в Visual Studio
2. Нажать F5 (или "Собрать" → "Собрать решение")
3. В стартовом окне нажать "№94"
4. Нажать "Построить график"
5. При желании сохранить координаты в файл
